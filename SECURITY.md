Security Policy
Supported Versions

UniVault is currently under active development.

Version	Supported
Latest	✅ Yes
Older versions	❌ No
Reporting a Vulnerability

If you discover a security vulnerability in UniVault, please report it responsibly.

Do not create a public GitHub issue for security vulnerabilities.

Instead, contact the project maintainers privately through GitHub.

When reporting a vulnerability, please include:

A clear description of the vulnerability

Steps to reproduce the issue

The potential impact

Screenshots or logs, if relevant

Any suggested fix, if available

What to Report

Security issues may include:

Authentication or login vulnerabilities

Unauthorized access to user accounts

Database security issues

API vulnerabilities

File upload vulnerabilities

Exposure of private user information

Authentication bypasses

Permission or authorization problems

Injection vulnerabilities

Sensitive information leaks

Protecting Sensitive Information

Never commit sensitive information to the repository, including:

Passwords
API keys
Database credentials
Secret tokens
Private keys
.env files containing secrets


Use the provided environment templates:

frontend/.env.local.example
backend/.env.example

Responsible Disclosure

Please allow the maintainers reasonable time to investigate and address a reported vulnerability before publicly disclosing it.

We appreciate responsible security research and contributions that help make UniVault safer for students and contributors.

Security Updates

Security fixes may be released through:

GitHub commits

Pull requests

Releases

Security advisories

Thank you for helping keep UniVault secure. 🔐
