Contributing to UniVault

Thank you for contributing to UniVault! 🎓

Getting Started

Fork the repository.

Clone your fork:

git clone https://github.com/phanuelagum96-collab/UniVault.git


Create a new branch:

git checkout -b feature/my-feature


Make your changes and test them.

Commit your changes:

git add .
git commit -m "feat: add my feature"


Push your branch:

git push origin feature/my-feature


Open a Pull Request.

Guidelines

Write clean and readable code.

Use meaningful commit messages.

Test your changes before submitting.

Do not commit passwords, API keys, or other secrets.

Keep Pull Requests focused on one change.

Be respectful to other contributors.

Project Structure
UniVault/
├── backend/

Reporting Issues

When reporting a bug, include:

What happened

Steps to reproduce it

Expected behaviour

Screenshots or error messages when useful

Thank you for helping make UniVault better! 🚀
